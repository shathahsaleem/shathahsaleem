### Key Projects

#### 1. JobRadar UAE — Multi-Agent Job System
* **What it does:** Uses 3 AI agents to scan UAE job boards, match skills, and draft tailored CVs and cover letters.
* **Why it's useful:** It has built-in safety rules so it never invents fake metrics or experience on your resume.
* **Tools used:** Python, LangGraph, Qdrant, Async Playwright, Ragas.

#### 2. AI Image & Content Matcher
* **What it does:** Reads images, categorizes them automatically, and pairs them with relevant blog posts.
* **Why it's useful:** If the AI is unsure (e.g., comparing a wolf image to a fox article), it rejects the match instead of guessing wrong.
* **Tools used:** Vision Models, Embeddings, Schema Validation.

#### 3. API Usage & Billing Engine
* **What it does:** Tracks software usage, counts AI tokens, and handles payments via Stripe.
* **Why it's useful:** Ensures customers are billed correctly without accidental double-charges if a network request retries.
* **Tools used:** Python, REST APIs, Stripe Webhooks.
