### Featured Engineering Projects

#### 1. Containerized Task Management API & Database Engine
* **What it is:** A production-ready REST API built with FastAPI, containerized using Docker Compose, and backed by PostgreSQL with isolated environment secrets.
* **Engineering Highlights:**<br>
  * Evolved storage from in-memory -> auto-initializing SQLite -> multi-container PostgreSQL with volume persistence.<br>
  * Enforced dynamic validation via Pydantic schemas and strict parameterized SQL queries to eliminate SQL injection vectors.<br>
  * Implemented standardized RESTful status handling (`200`, `201`, `204`, `400`, `404`, `422`) with automated Swagger UI interactive documentation.
* **Stack:** Python, FastAPI, Docker, Docker Compose, PostgreSQL, Pydantic, Git.

#### 2. UAE Unified Job Board Agent *(In Active Development)*
* **The Problem:** Job opportunities in the UAE are scattered across fragmented niche boards, LinkedIn, and direct portal URLs (`careers.[company].ae`). Great candidates miss roles simply because platform discovery is broken.
* **The Solution:** A multi-agent orchestration tool built with LangGraph and Playwright that automatically aggregates, deduplicates, and matches candidate profiles against company job portals without hallucinating qualifications.
* **Stack:** Python, LangGraph, Async Playwright, Qdrant, Pydantic.

### Lessons From the Trenches (AUS & Teamwork)

My degree at the **American University of Sharjah** taught me how systems actually work when they break:

* **Database Connections aren't Magic:** Surviving Web Application Programming meant wrestling Jakarta Servlets into talking to raw SQL databases piece-by-piece until data transactions executed seamlessly.
* **Leadership & Merge Conflicts:** As a project lead, I learned that engineering leadership isn't just writing code—it's managing rough deadlines, establishing Git workflows to resolve dirty merge conflicts when two members push to the same file, and keeping asynchronous teams aligned.
